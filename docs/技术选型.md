# K8s 智能监控平台技术选型

## 项目定位

本项目是一个基于 Prometheus、Grafana、Alertmanager、Loki 和大模型 API 的 Kubernetes 智能监控运维平台。

平台不替代 Prometheus、Grafana 或 Alertmanager，而是在它们之上做统一网站，提供监控展示、告警管理、日志查询、AI 故障分析、PromQL 生成、Runbook 推荐等能力。

## 云平台与集群

- 云平台：阿里云 ECS
- 集群架构：1 台 control-plane + 2 台 worker
- Kubernetes 发行版：K3s
- 操作系统：Ubuntu 22.04 / Ubuntu 24.04

推荐 ECS 配置：

- control-plane：2 核 4G，80G 云盘
- worker-1：4 核 8G，100G 云盘
- worker-2：4 核 8G，100G 云盘

## 后端技术

- 编程语言：Python
- Web 框架：FastAPI
- ASGI 服务：Uvicorn / Gunicorn
- HTTP 客户端：httpx
- 数据校验：Pydantic
- ORM：SQLAlchemy

- Kubernetes 接入：kubernetes Python client

后端主要接入：

- Prometheus API
- Alertmanager API
- Grafana API
- Kubernetes API
- Loki API
- 大模型 API
- PostgreSQL
- Redis

## 前端技术

- 框架：React
- 语言：TypeScript
- 构建工具：Vite
- UI 组件库：Ant Design
- 图表库：ECharts

主要页面：

- 登录页
- 首页总览
- 监控中心
- 告警中心
- 日志中心
- AI 智能助手
- 系统管理

## 数据库与缓存

- 数据库：PostgreSQL
- 缓存 / 任务支持：Redis

PostgreSQL 存储：

- 用户
- 角色
- 权限
- 监控对象配置
- 告警联系人
- AI 对话记录
- 系统配置
- 审计日志
- Runbook 知识库

Redis 用于：

- 缓存 Prometheus 查询结果
- 登录状态或 token 黑名单
- AI 分析任务状态
- 异步任务辅助

## 监控系统

- 指标采集与存储：Prometheus
- 可视化：Grafana
- 告警：Alertmanager
- 安装方式：Helm + kube-prometheus-stack
- K8s 状态指标：kube-state-metrics
- 节点指标：node-exporter
- 黑盒探测：blackbox-exporter，可选

kube-prometheus-stack 会安装：

- Prometheus
- Grafana
- Alertmanager
- Prometheus Operator
- kube-state-metrics
- node-exporter
- ServiceMonitor / PodMonitor / PrometheusRule CRD

## 日志系统

- 日志存储与查询：Loki
- 日志采集：Promtail
- 展示：Grafana
- AI 分析：后端调用 Loki API 获取相关日志，再交给大模型分析

第一版日志能力：

- 按 namespace 查询日志
- 按 pod 查询日志
- 按关键词查询日志
- 查询最近 5 分钟 / 30 分钟 / 1 小时日志

## AI 大模型

使用外部大模型 API，不自建大模型。

可选：

- OpenAI API
- Azure OpenAI
- 通义千问
- DeepSeek
- 智谱 GLM
- 豆包

AI 助手能力：

- 告警解释
- Pod 重启分析
- CPU / 内存异常分析
- PromQL 生成
- 日志摘要
- 故障原因定位
- 修复建议
- Runbook 推荐

AI 第一版只读，不自动执行删除、重启、扩容等危险操作。

## 容器与镜像

- 镜像构建：Docker
- K3s 容器运行时：containerd
- 镜像仓库：阿里云 ACR / Docker Hub

只有自己写的代码需要 Docker 打包：

- FastAPI 后端
- React 前端
- 可选 AI 分析 worker

第三方中间件通过 Helm Chart 或官方镜像部署：

- Prometheus
- Grafana
- Alertmanager
- PostgreSQL
- Redis
- Loki
- Promtail
- Nginx Ingress
- cert-manager
- node-exporter
- kube-state-metrics

镜像流程：

```text
源码
  -> Dockerfile
  -> docker build
  -> docker push 到阿里云 ACR / Docker Hub
  -> K3s 拉取镜像
  -> containerd 运行成 Pod
```

## 入口、域名与安全

- Ingress：Nginx Ingress / K3s 默认 Traefik
- HTTPS：cert-manager + Let's Encrypt
- 域名：阿里云域名
- DNS：阿里云云解析 DNS
- 认证：JWT
- 权限：RBAC
- 密码加密：bcrypt
- 敏感配置：Kubernetes Secret
- 审计：记录关键操作日志

公网暴露建议：

- 只暴露你的智能监控网站
- Prometheus、Alertmanager、Kubernetes API 不直接暴露公网
- Grafana 可以选择内嵌到网站或单独暴露

## 最终架构

```text
用户浏览器
  -> 域名 + HTTPS
  -> Ingress
  -> React 前端
  -> FastAPI 后端
      -> Prometheus API
      -> Grafana API
      -> Alertmanager API
      -> Kubernetes API
      -> Loki API
      -> PostgreSQL
      -> Redis
      -> 大模型 API

K3s 集群
  -> 1 台 control-plane
  -> 2 台 worker
```

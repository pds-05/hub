# Windows 服务器资源与服务状态异常

## 覆盖告警指标

`windows_cpu_usage_percent`、`windows_memory_usage_percent`、`windows_logical_disk_free_bytes`、`windows_service_state`

## 现象和触发条件

- Windows CPU/内存高、逻辑磁盘可用空间低，或被监控服务状态异常。

## 影响范围

- IIS、数据库、业务服务或 exporter 可能变慢、停止或无法写入日志/数据。

## 所需证据

- CPU、内存、磁盘趋势，服务名称/状态，事件查看器日志、最近补丁/发布与进程资源排序。

## 排查步骤

1. 使用任务管理器、资源监视器或 PowerShell 定位高 CPU/内存进程。
2. 使用 `Get-Service`、`sc query` 检查服务状态、启动类型和依赖服务。
3. 检查 Event Viewer 的 Application/System 日志和磁盘空间、日志增长、临时文件。
4. 对网络服务同时验证端口监听、防火墙和应用日志。

## 建议处置

- 修复异常进程、服务依赖、计划任务或日志增长；为关键服务配置恢复策略和开机自启。
- 磁盘空间不足时按数据保留策略清理或扩容，避免删除未知业务文件。

## 风险提示

- 不要直接结束系统服务或删除程序目录；先确认依赖和业务窗口。

## 恢复验证

- 服务为 Running，端口可访问，CPU/内存/磁盘恢复，事件日志无新增严重错误。

## 升级条件

- 核心 Windows 服务无法启动、系统盘耗尽、反复蓝屏/重启或存在数据损坏风险时，升级处理。
